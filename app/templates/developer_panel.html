Email Delivery Setup
Used to send access codes in bulk. Pick a provider, paste the key, set the sender, then send a test.
On Render, Gmail SMTP fails — Render Free blocks outbound SMTP ports (25/465/587), so Gmail (which only uses those ports) times out even with a valid app password. It works on your laptop because your laptop allows those ports. Fix: use Brevo (free, 300 emails/day) — it sends over HTTPS (port 443), which Render allows.
Get a free Brevo key: sign up at brevo.com → SMTP & API → API Keys → create one (starts with xkeysib-) → paste below. Verify your sender email in Brevo under Senders.
Google Drive Storage Setup
Proof photos are stored in Google Drive (15 GB free) and their links appear in the exported sheet. A safety copy also stays in Supabase.
Setup (one time): In Google Cloud Console create a Service Account → create a JSON key → paste the whole JSON below. In Google Drive create a folder, share it with the service account's email (Editor), and paste the folder ID (the part of the folder URL after /folders/).
