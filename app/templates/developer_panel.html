How to get a working Brevo API key
  1. Log in at brevo.com → your name (top right) → SMTP & API.
  2. Open the API Keys tab (not the SMTP tab) → Generate a new API key. It starts with xkeysib-.
  3. Copy it straight away (Brevo shows it only once), paste it above, click Save & verify.
  4. Senders, Domains & Dedicated IPs → Senders: add and verify the sender email you entered above.
  5. If you see an IP address error: Security → Authorised IPs → turn the restriction off (Render's IP changes).
